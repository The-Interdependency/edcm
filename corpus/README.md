# Corpus workspaces

`corpus/` stores committed, reviewable **evidence manifests** for bodies of work EDCM will analyze. It does not store generated embeddings, caches, or a centrally imposed domain ontology.

Each corpus owns its source identities, provenance, rights state, retrieval policy, and unresolved acquisition boundaries. Large acquired bytes and generated receipts belong under `artifacts/` and are ignored by Git.

## Usage

Start with the corpus-specific README and manifest. Validate or acquire through its declared runner rather than downloading source material ad hoc.
