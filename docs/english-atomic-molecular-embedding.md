# Historical English atomic/molecular experiment

The former EDCM-owned `UCNSObject`, fractional-angle placement, hash-derived
placement, and local product implementation are retired and absent from the
active language package. They remain recoverable from Git history only and are
not a fallback construction.

The active bounded lexical representation system is documented in
[`ENGLISH_LEXICAL_FLOOR.md`](ENGLISH_LEXICAL_FLOOR.md). It uses the exact
UCNS-owned metadata-free relational carrier and supplies no replacement
geometry.
