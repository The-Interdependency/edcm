## Consumer migration

Pass only raw inputs to `build_default_layers().run()`. Resubmitting a completed
pipeline dictionary now raises `ValueError`. Remove derived `rounds`, projections,
alerts, integration status, geometry, provenance and result fields; supply the
original transcript and authorized source inputs instead. Optional package
absence never authorizes retired evidence.

`build_result_contract()` assembles trusted in-process completed layer state.
It is not a raw-input ingress or an authentication API. A boolean execution flag
alone is not sufficient: complete, finite, indexed measurements and source must
also be present. Public `.run()` rejects that flag in caller input.

The parser recognizes labels at line starts, per line, across supported formats.
Unlabelled lines continue the current turn; preamble belongs to `SPEAKER`.
Label-like prose is syntactically ambiguous: use a declared input convention.
`ParsedTranscript.source_text` retains exact labels, spacing and line endings;
turn text excludes label syntax. A manually constructed parsed object may use
`source_text=None` to express unavailable original source.

Turn-content boundary: one terminal line ending before the next label or at
document end is separator syntax. Interior continuation and blank lines remain
content. Exact separator bytes remain available in `source_text`; they cannot
create an utterance identity difference merely because turns were reordered.

Recompute result identities under schema 2.0.0. Do not compare old and new hashes
as if they described an unchanged serialization. The whole-result hash detects
content changes, not authorship, truth, or empirical validity.

Codec 2 requires its explicit version and complete token entries. Old codec 1
archives cannot recover entries already discarded. Decode those archives with
the original pinned producer and label the missing information; do not silently
upgrade them to a lossless claim. Re-encode original source with 0.2.0 when it is
available. No duplicate legacy decoder is installed on the active path.

## Historical replay and research

Sealed reports, original candidate IDs, exact source commits, holdout outcomes
and frozen marker resources retain their original bytes. Replay a historical
claim from the EDCM and UCNS commits recorded in its artifact. Running a current
experiment runner creates new candidate evidence; it does not reproduce the old
measurement implementation merely because the experiment family name matches.

The parser repair can change metrics even for single labelled turns and can
change round membership for mixed formats or preamble. Existing fitted holdout
coefficients are historical evidence, not validation of candidate v2. This
repair does not retune thresholds, reinterpret negative results, or rerun a
sealed test to promote the new implementation.

The phrase “I cannot do this.” now reaches measurement in the audited multiline
example but still scores zero on the frozen refusal marker axis. Source fidelity
and construct validity are separate. See [upgrade avenues](../UPGRADE_AVENUES.md).
