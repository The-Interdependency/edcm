# UCNS–EDCM v0.3 serialization invariant

## Finding

The first v0.3 witness run found that the UCNS unordered-multiset projection correctly ignored event order, but the EDCM report signature serialized multiset groups in first-encounter order.

That serializer reintroduced the exact distinction the selected policy had declared irrelevant. Two repair-topology cases therefore appeared structurally different even though their full event multisets were equal.

## Corrected invariant

A report identity for a projected structural view must be canonical under that view's declared equivalence.

```text
ordered sequence -> preserve encounter order
multiset         -> sort stable keys and retain counts
set              -> sort stable keys and discard multiplicity
```

The report serializer may not preserve or invent distinctions excluded by the policy whose result it records.

## Evidence

The unchanged witness now establishes:

- `pressure -> repair` and `repair -> pressure` have equal full-event multisets;
- their final active-pressure readouts differ;
- full-multiset equivalence is therefore incompatible with that readout on the tested pair;
- full ordered sequence preserves the distinction.

## Status

Implemented and witness-backed in PR #38. This does not select a canonical structural policy; it constrains how every candidate policy must be serialized and identified.
