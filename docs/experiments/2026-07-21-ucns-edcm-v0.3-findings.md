## 1. Lexical occurrence is not operating assertion

### Negation

The phrase `penalty` appeared once in both cases:

```text
asserted: There is a penalty if you delay.
negated:  There is no penalty if you delay.
```

```text
v0.2 lexical constraint occurrences: 1.0 vs 1.0
v0.3 asserted constraint events:      1.0 vs 0.0
active-pressure UCNS W:               3.0 vs 1.0
```

The negated mention remained a positive structural cell. It was inactive as pressure but was not converted into absence.

The lexical-family multiset and set declared the structures equivalent after losing scope and surface. That equivalence was incompatible with the asserted-constraint readout.

**Pre-canon consequence:** a UCNS–EDCM object must retain both mention identity and assertion scope. Lexical-family equivalence is valid for mention-count questions but invalid for operating-pressure questions on this pair.

### Quotation and retraction


The quoted events remained represented with explicit quotation, attribution, and retraction state. A separate repair event retained the rescission.

### Hypothetical scope

The consequence phrase `access will be revoked` appeared in both an operative condition and an imagined condition.

```text

v0.3 asserted constraint events:      1.0 vs 0.0

```

The lexical-family multiset and set again became equivalent while the asserted readout differed.

**Pre-canon consequence:** conditional status and hypothetical status are distinct fields. A conditional consequence is not automatically inactive; an imagined or counterfactual consequence is not automatically operating pressure.

## 3. Local refusal negation requires family-level evidence

The positive and negated cases were:

```text
I refuse.
I do not refuse.
```

The v0.3 family-level layer retained one refusal mention in both cases:

```text
lexical refusal family mentions: 1.0 vs 1.0
owned active refusal events:      1.0 vs 0.0
active-pressure UCNS W:           3.0 vs 1.0
```

The v0.2 surface-phrase candidate reported `1.0 vs 0.0` because its phrase list recognized `I refuse` but not the embedded family mention in `I do not refuse`.

**Pre-canon consequence:** surface n-gram identity and event-family identity are separate layers. Exact phrases must remain available, but family-level scope analysis cannot depend on one preferred surface form.

The baseline `R_mean` also reported `1.0 vs 0.0`. This is consistent with the target ordering but does not establish a general negation model; it may reflect surface-marker behavior.


The full unordered multiset and full set correctly declared the retained event collections equivalent. They were incompatible with the final-active-pressure readout because they discarded order.

The full ordered view preserved the distinction.

All three tested UCNS scalar support totals were equal across this pair:


**Pre-canon consequence:** neither total support nor scalar breadth can replace sequence topology. Quantity of retained distinction and current circuit state are separate measurements.

The baseline κ falsifier shows that its current round grouping and recurrence did not preserve this particular repair-order distinction.

## 7. Policy-specific serialization is load-bearing

The first v0.3 witness run exposed an evidence-layer defect:

- UCNS multiset semantics correctly ignored event order;
- the report serializer emitted multiset groups in encounter order;
- the signature therefore reintroduced a distinction the policy had removed.

The serializer was corrected without changing the witness:

```text
ordered sequence -> retain encounter order
multiset         -> sort stable key/count pairs
set              -> sort stable keys
```

The unchanged repair-order witness then passed.

**Pre-canon consequence:** every projected structural identity must be canonical under the selected policy's declared equivalence. A serializer may not preserve or invent distinctions excluded by that policy.

See [`2026-07-21-v0.3-serialization-invariant.md`](2026-07-21-v0.3-serialization-invariant.md).

## Cumulative pre-canon constraints after v0.3

1. Preserve exact event order until a readout-specific policy explicitly discards it.
2. Preserve multiplicity even when a set view is also retained.
3. Separate surface phrase, event family, and scope state.
4. Preserve negated, quoted, hypothetical, attributed, and retracted mentions as positive evidence.
5. Do not treat inactive pressure as absent structure.
6. Preserve speaker ownership separately from lexical refusal family.
7. Treat repair and retraction as state transitions, not deletion.
8. Keep current state, peak state, accumulated state, and support quantity separate.
9. Require policy-canonical serialization for every projected identity.
10. Do not rely on baseline `C` as the sole constraint or scope instrument.
11. Do not treat baseline `R` pairwise success as proof of ownership or negation semantics.
12. Preserve all v0.1–v0.3 falsifiers as permanent evidence.

## Next experiment boundary

Version 0.4 should test discourse-linked scope rather than local sentence scope:

- correction targets across turns;
- anaphora such as `that requirement` and `it`;
- nested quotation and quotation boundaries;
- temporary versus permanent suspension;
- conditional activation and deactivation;
- contradiction by the same versus a different speaker;
- scope inheritance through reply structure;
- multiple candidate graphs for which earlier event a repair modifies.

This is the next reciprocal construction problem: EDCM needs relation-bearing event history, and UCNS must preserve competing graph and sequence interpretations until experiments determine which are required by each readout.
