# UCNS–EDCM experiment v0.2 — falsifier expansion and calibration

**Status:** executable pre-canon experiment design.  
**Prior evidence:** `edcm.ucns-edcm-experiment-report/0.1.0`.  
**Prior report digest:** `4c8bd8496ec549c1073320bafc995c7c65eaf81c9385e4dc6fff7794ed3b1124`.  
**Canon selection:** none.

## Purpose

Version 0.1 established that order and multiplicity are load-bearing for the tested EDCM readouts and produced two direct falsifiers:

1. the frozen baseline `R_mean` saturated on one versus repeated refusal;
2. the frozen baseline `C_mean` missed the tested holdout constraint phrasing.

Version 0.2 does not edit those results or silently repair the frozen baseline. It adds a separate candidate and a larger fixed corpus designed to determine the boundaries of those failures.

## Experiment dimensions

### Refusal dose

The program measures zero, one, two, and four refusal occurrences using several phrasings.

It reports:

- raw refusal occurrences;
- refusal rate;
- accumulated and terminal candidate tension;
- frozen baseline `R_mean`;
- occurrence-weighted UCNS breadth.

A plateau is retained as a named result rather than hidden by averaging.

### Constraint paraphrase coverage

Four high/low families are tested:

- known obligation and removed-alternative phrasing;
- only-permitted-option plus deadline phrasing;
- adverse-consequence phrasing;
- mandatory-authority phrasing.

Each family records high and low values separately for:

- the occurrence-and-coverage EDCM candidate;
- the frozen baseline `C_mean`;
- dissonance-weighted UCNS breadth.

A signal on the low-pressure control is recorded as a false-positive/control signal, not discarded.

### Resolution latency

The same circuit class is tested with:

- immediate repair;
- delayed repair after a second pressure-refusal cycle;
- no repair;
- repair before later pressure.

The program separates:

- pressure-to-resolution horizon;
- peak tension;
- accumulated tension;
- terminal tension;
- frozen baseline energy and final κ.

No one summary is allowed to replace the others.

### Support assignment

Four UCNS support policies coexist:

- `unit-turn`;
- `token-turn`;
- `occurrence-turn`;
- `dissonance-turn`.

For every declared contrast, the report records whether each support policy preserves, collapses, or reverses the expected ordering under the UCNS `cell-detail` breadth candidate.

These support assignments are candidates. A stable ranking across several policies is evidence; it is not a vote and does not select canon.

## New EDCM candidate

`edcm-occurrence-coverage-v1` is transparent and deliberately limited.

It differs from the frozen baseline by:

- retaining raw occurrence counts rather than clipping each turn-level signal to `[0,1]`;
- grouping constraint phrases into explicit families;
- reporting resolution latency separately from final tension;
- retaining peak, accumulated, and terminal tension independently.

Its phrase lists and recurrence coefficients remain candidate parameters subject to falsification.

## Usage

```bash
python -m pip install -e .[dev,ucns-experiments]
export UCNS_SOURCE_ROOT=/path/to/ucns-at-5331ae9
python -m pytest -q tests/test_ucns_edcm_experiments_v2.py
python -m edcm.ucns_edcm_experiments_v2 \
  --ucns-source-root "$UCNS_SOURCE_ROOT" \
  --output artifacts/ucns-edcm-v0.2.0.json
```

Run the command twice and require byte-identical reports.

## Nonclaims

This experiment does not establish:

- canonical EDCM axes or phrase families;
- canonical recurrence coefficients;
- canonical UCNS support `mu`;
- canonical structural equivalence;
- canonical product character `M`;
- canonical faithful breadth `B`;
- diagnosis, intention, morality, consciousness, or external truth.
