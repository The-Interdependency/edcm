## 1. Reference existence, resolution, and state transition are separate

Version 0.4 represented each later reference independently from the resolver edge selected for it.

The ambiguous anaphora case contained one positive reference expression:

```text
That requirement is suspended.
```

The explicit-only resolver remained unresolved:

```text
explicit unresolved references: 1
nearest unresolved references:  0
```

Both resolutions retained equal node-reference support:

```text
explicit node-reference W: 3.0
nearest node-reference W:  3.0
```

**Pre-canon consequence:** unresolved does not mean absent. A reference must remain positive retained evidence even when a resolver fails to select a target.

## 2. Ambiguity is a bundle of graphs, not one preferred graph

The ambiguity-preserving resolver retained two graph interpretations for both the anaphora and ambiguous-repair cases:

```text
anaphora alternatives: 2
anaphora state divergence: 1

repair alternatives: 2
repair state divergence: 1
```

The repair ambiguity bundle's exact ordered labeled signature was:

```text
615293d4a1c4f021781fd0eded0e32d1cd868f479036dc45b4290182b75fd6a1
```

The nearest-compatible bundle signature was different:


**Pre-canon consequence:** a structural comparison must use the complete alternative bundle. Selecting `interpretations[0]` silently converts ambiguity into a preferred answer and destroys option capacity.

## 3. Explicit and ordinal target identity survived

Explicit label resolution preserved which requirement was retracted:

Ordinal resolution likewise preserved first versus second target selection.

**Pre-canon consequence:** label and ordinal target identity are load-bearing graph structure. Flat event counts cannot replace them.

## 4. Nearest-compatible failed speaker ownership

The ownership case contained:

```text
A: Submit the form.
B: Attend the briefing.
A: I withdraw my requirement.
```

Same-speaker-nearest selected A's requirement:

```text
gold hits:                 1.0
A active requirements:     0.0
```

Nearest-compatible selected the more recent B requirement:

```text
gold hits:                 0.0
A active requirements:     1.0
```

The hypothesis that nearest-compatible would equal the ownership-aware resolver was falsified.

**Pre-canon consequence:** speaker ownership is not an optional annotation for first-person reference. It must remain available to graph resolution and downstream state readouts.

## 7. Nested quotation is not transitive retraction

The nested case represented:

```text

```

Quote containment was retained as a distinct labeled edge.

Explicit-reference retracted only the notice:


Family-wide also retracted the inner command:

```text

```

**Pre-canon consequence:** containment, quotation, and retraction are separate relation types. Retracting a container does not automatically retract every nested statement unless a declared policy explicitly says so.

## 9. Graph evidence integrity is itself load-bearing

Automated review found five evidence defects before materialization:

1. ambiguity comparisons selected only the first interpretation;
2. unresolved references existed only in retained layers and not positive support;
3. speaker-scoped active state was absent;
4. quote containment was absent from graph identities;
5. declared baseline and scalar falsifiers were not relation-verdict rows.

The repaired report now includes:

- a `__bundle__` signature for every resolver/support/view combination;
- positive reference cells for resolved and unresolved references;
- speaker-scoped active-state readouts;
- quote-containment edges in graph identity and graph-bearing support;
- five explicit falsified relations and a positive node-edge control.

**Pre-canon consequence:** an experiment cannot claim to test a distinction that its evidence schema does not retain.

## 10. Cumulative pre-canon constraints after v0.4

1. Preserve reference expressions separately from selected targets.
2. Preserve unresolved references as positive evidence.
3. Preserve every admissible graph alternative until a scoped policy selects among them.
4. Compare ambiguity bundles rather than one conveniently ordered interpretation.
5. Preserve relation labels, direction, and target identity.
6. Preserve speaker ownership for ownership-sensitive references.
7. Preserve quote containment separately from retraction and other state transitions.
8. Treat suspension, resumption, activation, deactivation, contradiction, repair, and retraction as distinct operations.
9. Keep node/reference quantity separate from edge quantity and graph-dependent state.
10. Do not expect a scalar support total to replace a graph.
11. Keep local scope metrics separate from discourse-linked state.
12. Preserve falsified resolvers and metrics as provenance-bearing evidence.
13. Require every claimed experimental distinction to appear in the report schema and reproducible artifact.
