# UCNS–EDCM experiment v0.4 — discourse-linked scope graphs

**Status:** executable pre-canon experiment design.  
**Prior evidence:** v0.1, v0.2, and v0.3 remain immutable.  
**v0.3 report digest:** `5baf611b5930d271a0fa7dbc977a55c7748b0891196d619b4695e39308cff37b`.  
**Canon selection:** none.

## Purpose

Version 0.3 established that an event's operating state depends on scope and that repair topology is order-bearing. It deliberately stopped before the harder question:

> Which earlier event does a later correction, suspension, retraction, activation, quotation, or contradiction modify?

Version 0.4 tests discourse-linked scope as a graph problem. It preserves the reference expression itself, every plausible target, every selected edge, and every graph-dependent state result.

No target resolver is universal by default. Ambiguity is positive retained evidence, not a parser failure to hide.

## Primary doctrine

A discourse-linked UCNS–EDCM object contains at least three distinguishable layers:

1. **event nodes** — testimony-bearing mentions and state-bearing events;
2. **reference expressions** — later language that points backward, forward, or conditionally;
3. **candidate relation edges** — named resolver outputs connecting references to possible targets.

These layers may not be flattened into a single active/inactive flag.

```text
reference exists != target resolved
one target selected != only target admissible
edge selected != edge canonical
state transition != source event deletion
```

## Fixed graph candidates

Five target-resolution candidates coexist.

### 1. Explicit-reference

Uses only explicit labels, ordinals, quoted identifiers, or exact target names. It fails closed on pronouns or underspecified phrases.

### 2. Nearest-compatible

Selects the nearest preceding node matching the requested event family or state type, regardless of speaker.

### 3. Same-speaker-nearest

Selects the nearest compatible preceding node owned by the reference speaker when available; otherwise remains unresolved.

### 4. Family-wide

Connects a reference to every preceding node in the matching event family. This intentionally pressures over-broad repair and retraction.

### 5. Ambiguity-preserving

Retains every plausible target as a set of alternative graph interpretations rather than forcing one edge. Alternatives are bounded and independently identified.

No candidate is the default or canon.

## Relation types

The fixed program uses named directed relations:

```text
retracts
suspends
resumes
activates
deactivates
repairs
contradicts
quotes
attributes
clarifies
```

Relation labels remain part of graph identity. An unlabeled edge view is available only as an explicit lossy projection.

## Event-state model

The transparent discourse candidate retains these states separately:

```text
active
suspended
retracted
conditional-pending
inactive-by-condition
quoted-only
attributed-only
contradicted-but-active
unresolved
```

A contradiction does not automatically retract another speaker's event. A suspension does not delete its target. A resumption does not create a new historical event in place of the original. Conditional activation and deactivation must retain the condition evidence that caused the transition.

## Fixed corpus dimensions

### Explicit target selection

Two active requirements are introduced under labels `R1` and `R2`. A later statement retracts either `R1` or `R2`. Explicit-reference should preserve the named distinction; family-wide should over-retract.

### Ordinal target selection

Two requirements appear without symbolic labels. A later statement retracts "the first requirement" or "the second requirement."

### Ambiguous anaphora

Two compatible requirements precede "that requirement is suspended." Ambiguity-preserving should retain multiple alternatives; explicit-reference should remain unresolved.

### Speaker ownership

Two speakers issue compatible requirements. One later says "I withdraw my requirement." Same-speaker-nearest should preserve ownership; nearest-compatible may attach to the wrong speaker when the most recent requirement belongs to another.

### Nested quotation

A current speaker quotes a notice that itself quotes an earlier command. A later rescission targets the notice, not automatically the inner quoted command. Quote-containment edges and retraction edges remain distinct.

### Temporary suspension and resumption

A requirement is suspended until noon and later resumed. The historical requirement, suspension, and resumption all remain represented.

### Conditional activation

A consequence is conditional on an audit failure. One case records failure; another records success. The same conditional node changes operating state through different activation/deactivation edges.

### Contradiction ownership

Speaker A issues a requirement. Speaker B denies that it applies. Another case has A retract the requirement. Contradiction and self-retraction must not be treated as the same transition.

### Competing repair graphs

Two earlier pressure events can both plausibly be the target of "the earlier instruction is corrected." Alternative graph interpretations produce different active-state summaries.

## Transparent discourse readouts

Each graph interpretation reports independently:

- node count;
- reference count;
- selected edge count;
- unresolved reference count;
- alternative interpretation count;
- active, suspended, retracted, and conditional node counts;
- active constraint count by speaker;
- contradiction count;
- state-divergence count across alternatives;
- graph identity and active-state identity.

No scalar total replaces the graph.

## UCNS representation

Each event node becomes a positive cell. Every reference expression becomes a positive reference cell whether it resolves, remains unresolved, or participates in several alternatives. Each selected relation edge and each quote-containment edge becomes a positive edge cell in graph-bearing support policies. Raw references and all candidate target sets also remain retained layers.

Three support assignments coexist:

1. `node-reference` — counts event nodes and every reference expression while selected edges remain outside the cell sum;
2. `node-edge` — counts nodes, references, quote-containment edges, and selected labeled edges;
3. `state-detail` — adds candidate state detail without erasing inactive or unresolved evidence.

All evidence remains positive. An unresolved reference does not receive zero support merely because no target was selected.

## Structural graph views

The report records at least:

- exact ordered labeled graph;
- labeled directed multigraph without event encounter order;
- unlabeled directed multigraph;
- flat node multiset;
- active-state summary;
- ambiguity bundle identity containing all alternative graphs.

Exact and labeled graph identities retain quote containment. Each resolution also has a bundle identity computed across all of its graph alternatives; no pairwise comparison may silently select only the first alternative.

Every projection records discarded dimensions, including:

```text
order
edge labels
edge direction
node labels
speaker ownership
reference identity
alternative multiplicity
state
```

## Fixed falsifiers

The program deliberately tests whether:

- explicit-reference can preserve label and ordinal targets;
- nearest-compatible misattaches ownership-sensitive references;
- family-wide over-retracts or over-suspends;
- ambiguity-preserving exposes divergent outcomes instead of hiding them;
- baseline EDCM collapses discourse-linked target differences;
- v0.3 local scope counts remain invariant when only relation targets change;
- flat node or edge-unlabeled views become equivalent while active-state readouts differ;
- node-reference scalar support remains invariant across graph-edge changes;
- node-edge support preserves selected-edge multiplicity;
- nested quotation is incorrectly treated as transitive retraction;
- contradiction is incorrectly treated as retraction.

A failed expected relation remains evidence and does not fail the build.

## Interpretation firewall

This experiment tests declared synthetic discourse graphs. It does not establish external truth, intention, legal authority, diagnosis, morality, or general natural-language understanding.

Human-authored node/reference annotations in the fixed corpus are experiment inputs. Resolver performance against those declarations does not make the annotation scheme universal.

## Nonclaims

Version 0.4 does not establish canonical discourse linking, anaphora resolution, relation labels, resolver precedence, EDCM recurrence, UCNS support, structural equivalence, `M`, `B`, thresholds, diagnosis, intention, morality, consciousness, or theorem status.
