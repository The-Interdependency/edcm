# UCNS–EDCM experiment v0.3 — assertion and scope topology

**Status:** executable pre-canon experiment design.  
**Prior evidence:** v0.1 and v0.2 remain immutable.  
**v0.2 report digest:** `85d6a9c7504a7e9b7fdb21e0dec5ff8e588d12e9d893f1a22854c1ae2ebbf0e4`.  
**Canon selection:** none.

## Purpose

Version 0.2 showed that lexical occurrence is not semantic assertion. The phrase `penalty` was counted inside `without penalty`, creating a false positive on a low-pressure control.

Version 0.3 pressures the distinction between **mention** and **operating event**. It tests matched or nearly matched lexical evidence under different scope topology:

- asserted versus negated;
- direct versus quoted and rescinded;
- operative conditional versus hypothetical or counterfactual;
- speaker-owned versus attributed refusal;
- repair after pressure versus pressure after repair;
- active statement versus retracted statement.

The experiment does not assume one universal scope parser. It introduces a transparent candidate and preserves the baseline and v0.2 occurrence candidate as competing instruments.

## Evidence layers

Every detected event retains separate fields for:

```text
family
phrase
speaker
turn index
polarity
quoted
hypothetical or counterfactual
conditional
attributed
retracted
direct or speaker-owned
active under the candidate policy
```

A negated or quoted mention remains structural evidence. It is not represented as absence and therefore may not be assigned `mu = 0` merely because it is inactive as pressure.

## Scope-bearing EDCM candidate

`edcm-scope-assertion-v1` reports independently:

- lexical constraint and refusal mentions;
- asserted active constraint events;
- negated mentions;
- quoted mentions;
- hypothetical/counterfactual mentions;
- conditional mentions;
- attributed refusal mentions;
- speaker-owned refusal events;
- repair and retraction events;
- final active pressure;
- peak active pressure;
- accumulated active pressure;
- pressure-to-repair horizon.

These are candidate readouts. The phrase families, local-scope windows, event-state rules, and recurrence remain falsifiable.

## UCNS event representation

Each scope event becomes a retained UCNS cell with explicit scope state. Three support assignments coexist:

1. `mention-event`: one unit for every retained event occurrence;
2. `scope-detail`: one unit plus retained scope complexity;
3. `active-pressure`: one unit plus candidate-active pressure/refusal contribution.

All retained events have positive support. `active-pressure` does not erase negated, quoted, or repaired evidence; it changes only the additional contribution.

## Structural views

The report records:

- full ordered event sequence;
- full unordered multiset;
- full set;
- lexical-only multiset;
- lexical-only set.

The lexical-only views explicitly declare scope loss. On matched pairs they test whether discarding scope would make structures appear equivalent while EDCM readouts remain different.

## Fixed pair families

### Negation

The same pressure phrase appears as assertion and denial:

```text
There is a penalty if you delay.
There is no penalty if you delay.
```

### Quotation and retraction

The same command appears directly and inside a rescinded quotation:

```text
You must comply immediately.
The notice said "You must comply immediately," but it was rescinded.
```

### Operative versus hypothetical condition

Revocation language appears as an active condition and as an imagined counterfactual.

### Refusal ownership

`I refuse` appears as the current speaker's act and as another person's quoted speech followed by present agreement.

### Repair topology

The same pressure and repair events appear in opposite order:

```text
pressure -> repair
repair -> pressure
```

An order-blind structure should become equivalent while final active pressure changes.

### Retraction

The same mandatory statement is either left active or explicitly withdrawn.

## Expected falsifiers

The experiment deliberately retests:

- whether baseline `C` or `R` distinguish direct from scoped-out mentions;
- whether the v0.2 occurrence candidate counts matched lexical evidence equally despite scope;
- whether lexical-only UCNS views collapse readout-bearing distinctions;
- whether full set or multiset semantics erase repair topology;
- whether the new scope candidate creates false positives or false negatives under local scope rules.

A failed expected relation remains evidence.

## Usage

```bash

export UCNS_SOURCE_ROOT=/path/to/ucns-at-5331ae9
python -m pytest -q tests/test_ucns_edcm_experiments_v3.py

  --ucns-source-root "$UCNS_SOURCE_ROOT" \

```

Run twice and require byte-identical reports.

## Nonclaims

This experiment does not establish canonical natural-language scope, event ownership, truth, intention, EDCM axes, UCNS support, structural equivalence, `M`, `B`, diagnosis, morality, consciousness, or theorem status.

## hmmm
