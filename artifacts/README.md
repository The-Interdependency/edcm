# Generated artifacts

`artifacts/` is the local materialization surface for reproducible generated evidence, receipts, caches, and later EDCM/UCNS outputs. Generated contents are ignored by Git except for directory README files.

Committed source manifests belong in `corpus/`; package implementation belongs in `edcm/`; generated evidence belongs here.

hmmm: artifact publication and long-term external storage are not selected by this directory convention.
